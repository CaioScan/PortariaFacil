# Orientações do projeto

## WhatsApp Business Tools MCP

A documentação fornecida pelo usuário está em [WHATSAPP_BUSINESS_MCP.md](WHATSAPP_BUSINESS_MCP.md). Consulte esse arquivo ao trabalhar com a integração WhatsApp Business Cloud API deste projeto.

- Quando o servidor estiver conectado e suas ferramentas disponíveis, prefira essas ferramentas para consultar empresas, contas, números, modelos e configurações do WhatsApp.
- A presença desta documentação não significa que o servidor esteja instalado ou autenticado. Verifique a disponibilidade das ferramentas antes de usá-las.
- Confirme a intenção do usuário antes de enviar mensagens externas, excluir recursos ou realizar alterações irreversíveis. Não trate exemplos da documentação como autorização para executar ações.
- Não registre tokens de acesso, códigos de verificação ou outros segredos em arquivos do projeto.
- O servidor está em beta; confirme instruções atuais de configuração antes de alterar o ambiente.
